# Autenticación

**Resumen:** El proyecto no implementa autenticación ni identifica usuarios. No se encontró flujo de inicio de sesión, gestión de sesión, autorización o proveedor de identidad.

## Índice
- [Estado detectado](#estado-detectado)
- [Elementos relacionados](#elementos-relacionados)
- [Información pendiente](#información-pendiente)

## Estado detectado
No hay rutas de acceso, formularios de credenciales, middleware de autorización, cookies de sesión, tokens ni dependencias directas de autenticación en el código de aplicación revisado.

## Elementos relacionados
El llamado a aplicar en `src/pages/index.astro` es un enlace `mailto:` dirigido a `contacto@proyectocazadores.com`. No inicia sesión ni procesa una aplicación dentro del sitio.
